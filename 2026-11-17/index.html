Is the AI confused by the question, or does it just not know?

When a large language model gives a shaky answer, the fix depends on the cause. This paper asks a question in several reworded versions, samples several answers to each version, turns every answer into a point in an embedding space, and splits the spread of those points exactly into a part that stays within a wording (aleatoric uncertainty) and a part that changes between wordings (epistemic uncertainty). It works with nothing but the model's text outputs, and adds a one-line correction for a bias that otherwise makes answer noise look like a knowledge gap.

Wang Ma, Debarun Bhattacharjya, Junkyu Lee, Nhan H. Pham, Harsha Kokel, Qiang Ji

Why it matters

When a chatbot may be wrong, the right response depends on why: an ambiguous question calls for clarification, while a gap in the model's knowledge calls for a search or a human, yet existing black-box checks give only one "how unsure" number. This paper splits that number into the two parts using only sampled answers to reworded prompts, with a one-line bias correction that cuts the false link between the two parts from a rank correlation of 0.65 to 0.12 at three answers per wording, and it ranks wrong answers about as well as methods that need the model's internals.

The paper

Black-Box Uncertainty Quantification for Large Language Models via Ensemble-of-Ensembles

Wang Ma (Rensselaer Polytechnic Institute), Debarun Bhattacharjya (Lirio), Junkyu Lee (IBM Software Innovation Lab), Nhan H. Pham (independent researcher), Harsha Kokel (IBM Software Innovation Lab), Qiang Ji (Rensselaer Polytechnic Institute); work done at IBM Research. arXiv:2611.18453 [cs.LG], 13 November 2026. Accepted at NeurIPS 2026. Read on arXiv · PDF · Code

In plain language: the outer ensemble is N meaning-preserving paraphrases x1…xN of the question (picked by adding small noise to the question's embedding and snapping to the nearest cached paraphrase). The inner ensemble is M sampled answers to each paraphrase, each embedded as a vector zi,j. The law of total covariance splits the total spread exactly:

Cov(Z) = EΔ[Cov(Z | Δ)] + CovΔ(E[Z | Δ])   i.e.   UT = UA (within wordings) + UE (between wordings)

With per-paraphrase means μ̂i and covariances Σ̂i (divisor M − 1), the estimators are

ÛA = (1/N) Σi Σ̂i,    ÛEraw = 1/(N−1) Σi (μ̂i − μ̄)(μ̂i − μ̄)⊤,    ÛE = ÛEraw − ÛA/M,    ÛT = ÛA + ÛE

Because each μ̂i is itself an average of only M noisy answers, the raw between-wording spread is inflated by exactly UA/M; subtracting ÛA/M makes ÛE unbiased for any M ≥ 2. Each matrix is reduced to a score by its trace. The paper also proves that on questions where the model answers the same way every time for a given wording but changes with the wording (confident hallucinations, prompt-format artefacts), any check based only on repeated answers to one prompt scores exactly zero while the between-wording part stays positive.

Tested on five short-answer benchmarks (TriviaQA, TruthfulQA, SciQA, GPQA, CoQA) with LLaMA-3 8B/70B and Qwen2.5 7B/72B. In the clarification test only the scores that use reworded prompts moved; every check based on a single fixed prompt stayed statistically unchanged, as the separation theorem predicts. Results vary by dataset: on some columns, such as GPQA with Qwen2.5-7B, all methods are close to chance.

How to use it

  • Try the examples: "Ambiguous question" makes each colour a wide cloud sitting in the same place (high aleatoric); "Knowledge gap" makes tight clouds in different places (high epistemic).
  • Watch the confident hallucination: every wording gives the same answer every time, so the single-prompt consistency check reads exactly 0, yet the rewordings disagree and the epistemic score catches it.
  • See the bias: with M = 2 or 3 the raw epistemic score (purple) sits well above the true value, by UA/M. The corrected score (orange) is centred on the truth at every M. Set σE to 0 to see the raw score invent a knowledge gap that is not there.
  • Trade off cost: the total cost is N × M model calls. More rewordings N narrows the spread of the epistemic estimate; more answers M mainly shrinks the bias the correction removes. Note the corrected score can dip below zero on a single run, since it is unbiased rather than clipped.

Simplifications: real answers are embedded by a sentence encoder in hundreds of dimensions; here the embeddings are 2-D with isotropic Gaussian noise, the per-rewording means are drawn as μi ~ N(0, σE²I) and answers as zi,j ~ N(μi, σA²I), so the true scores are UA = 2σA² and UE = 2σE². The single-prompt check is the trace of the sample covariance of M answers to the original wording, standing in for fixed-prompt methods such as self-consistency or embedding variance.
